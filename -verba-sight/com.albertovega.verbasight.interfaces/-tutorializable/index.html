interface Tutorializable

Tutorializable es una interfaz para implementar un tutorial guiado para nuevos usuarios.

El propósito es ofrecer una experiencia interactiva de introducción, generalmente utilizando librerías como TapTargetView. Esta interfaz permite a cualquier actividad que la implemente gestionar su propio tutorial sin duplicar lógica.

Se espera que la implementación de showTutorialIfNeeded contenga la lógica necesaria para comprobar si el tutorial ya fue mostrado (mediante SharedPreferences, com.albertovega.verbasight.utils.TutorialManager) y para lanzarlo si es necesario.
