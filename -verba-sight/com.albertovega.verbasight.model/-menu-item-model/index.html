MenuItemModel

open class MenuItemModel

Clase modelo que representa un item del menu principal de la aplicacion VerbaSight.

Cada objeto de esta clase contiene la informacion necesaria para mostrar una opcion del menu, incluyendo su titulo, el recurso del icono y la Activity que debe lanzarse al seleccionarla.

Es utilizada por el adaptador del menú MenuAdapter y por el ViewModel MainMenuViewModel para construir dinamicamente el menu de navegacion.
