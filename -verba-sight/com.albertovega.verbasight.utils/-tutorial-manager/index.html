TutorialManager

open class TutorialManager

Clase encargada de gestionar el estado de visualizacion de los tutoriales guiados en la aplicacion VerbaSight.

Utiliza SharedPreferences para almacenar si cada seccion (menu, transcripcion, reproductor de subtitulos) ya ha mostrado su tutorial al usuario. Esto permite que cada tutorial se muestre solo una vez.

Esta clase necesita que se le facilite un contexto (por ejemplo, una Activity) para funcionar. Se ha creado la interfaz Tutorializable para que se implemente de manera correcta en las Activities necesarias.
