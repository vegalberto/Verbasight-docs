BaseActivity

abstract class BaseActivity

BaseActivity es una clase base abstracta pensada para que todas las actividades de VerbaSight puedan aplicar correctamente el idioma elegido por el usuario antes de que se muestre la interfaz.

En Android, los textos e idiomas se cargan muy pronto, incluso antes del método onCreate().

Esta clase llama a applyLanguage para obtener un nuevo contexto con el idioma configurado por el usuario, ya sea español o inglés. Cualquier actividad que herede de BaseActivity aplicará automáticamente el idioma.

Esta técnica es común en apps multilingües y está alineada con las recomendaciones oficiales de Android:

  • Guía oficial de localización en Android
  • attachBaseContext() en Application
  • createConfigurationContext() en Context
