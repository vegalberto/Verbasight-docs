MainMenuActivityEspressoTest

open class MainMenuActivityEspressoTest

Prueba instrumentada con Espresso que verifica el funcionamiento del menu principal.

Este test comprueba que al hacer clic en el item de "Reconocimiento de Voz" en el menu principal, se lanza correctamente la actividad SpeechRecognitionActivity.

Tambien desactiva el tutorial y concede el permiso de microfono automaticamente para evitar interferencias durante la prueba. Sin desactivar el tutorial el test falla ya que no puede hacer click al menu. Conceder el permiso es para no ver la ventana de solicitud de permiso en el test.
