MainMenuActivity

open class MainMenuActivity : BaseActivity, MenuAdapter.OnMenuItemClickListener, Tutorializable

MainMenuActivity es la actividad principal del menu de navegación.

Esta pantalla muestra un menu de opciones al usuario utilizando un RecyclerView en formato de cuadrícula. Permite interactuar con las opciones del menú.

Las opciones del menú son las siguientes:

  • Reconocimiento de voz: Iniciará la actividad del reconocimiento de voz (SpeechRecognitionActivity).
  • Reproducción de subtítulos: Iniciará la actividad del reproductor de subtítulos (SubtitlePlayerActivity) y cargará automáticamente el subtítulo para reproducirlo.
  • Historial (de transcripciones): Iniciará la actividad del historial de transcripciones (HistoryActivity) y mostrará automáticamente un listado con las transcripciones exportadas previamente.
  • Ajustes: Iniciará la actividad de los ajustes (SettingsActivity).

La actividad se estructura mediante el patrón MVVM, observando los datos expuestos por MainMenuViewModel y representandolos mediante el adaptador MenuAdapter.

Además, implementa Tutorializable para ofrecer un tutorial guiado al usuario la primera vez que abre la aplicación (o resetea el tutorial) utilizando la librería com.getkeepsafe.taptargetview.TapTargetView.
