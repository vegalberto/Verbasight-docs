SpeechRecognitionActivity

open class SpeechRecognitionActivity : BaseActivity, Tutorializable, TranscriptionExportable

SpeechRecognitionActivity es una actividad encargada de realizar el reconocimiento de voz en tiempo real mediante la librería Vosk, y mostrar en pantalla los subtítulos generados dinámicamente conforme el usuario habla.

Esta actividad representa una de las funcionalidades principales de la aplicación VerbaSight, enfocada en mejorar la accesibilidad para personas con discapacidad auditiva, permitiéndoles visualizar transcripciones instantáneas en gafas de realidad aumentada o directamente en pantalla.

Principales características:

  • Obtención de permisos para capturar audio
  • Carga del modelo Vosk desde la clase de aplicación personalizada VerbasightApp
  • Inicio y gestión del reconocimiento de voz en tiempo real
  • Visualización de subtítulos mediante SubtitleView
  • Gestión del estado de reconocimiento de voz mediante SpeechRecognitionViewModel
  • Exportación de transcripciones mediante ExportTranscriptionDialogFragment
  • Inclusión de un tutorial visual interactivo para explicar su funcionamiento al usuario

Se integra con el patrón de arquitectura MVVM, separando la lógica del reconocimiento en el ViewModel SpeechRecognitionViewModel y permitiendo una gestión reactiva del estado con LiveData.

Además, implementa las interfaces TranscriptionExportable para la exportación de subtítulos y Tutorializable para mostrar el tutorial al usuario si es la primera vez que abre la actividad o si ha vuelto a activar los subtítulos desde las opciones de SettingsActivity.
