SubtitlePlayerActivity

open class SubtitlePlayerActivity : BaseActivity, Tutorializable

SubtitlePlayerActivity es una actividad encargada de reproducir subtítulos (.srt) sincronizados en tiempo real sobre la pantalla del dispositivo móvil.

Esta actividad permite al usuario:
  • Cargar manualmente un archivo de subtítulos en formato .srt desde el almacenamiento del dispositivo.
  • Visualizar la línea actual de subtítulo sincronizada con el tiempo.
  • Controlar la reproducción mediante botones de play/pausa, avance y retroceso rápido o preciso.
  • Usar una barra de progreso interactiva para desplazarse manualmente entre los subtítulos.

Al cargar correctamente un archivo, se analiza con SRTParser, y el texto resultante se gestiona a través del SubtitleViewModel, asegurando separación entre la lógica y la interfaz de usuario (MVVM).

Además, puede iniciarse directamente desde otra actividad (por ejemplo, HistoryActivity) si esta le pasa una URI con un archivo .srt. En este caso, la carga es automática.

La interfaz se adapta automáticamente a orientación horizontal para mejorar la experiencia visual del usuario durante la reproducción.

También implementa Tutorializable para mostrar un tutorial interactivo la primera vez que se accede a esta pantalla (o si se reactiva), guiando al usuario sobre cómo utilizar sus principales funciones. El tutorial se gestiona mediante TutorialManager y se implementa con la librería com.getkeepsafe.taptargetview.TapTargetView.
