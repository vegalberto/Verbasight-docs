MainMenuViewModelTest

open class MainMenuViewModelTest

Prueba unitaria para el MainMenuViewModel. Este controla el menú principal.

Verifica que el método setMenuItems() actualiza correctamente el LiveData con la lista de opciones de menú.

Para realizar este test, se usa InstantTaskExecutorRule. Al usar el patrón MVVM, se hace uso de LiveData, está diseñada para trabajar de forma asíncrona, es decir, solo notifica a listeners activos (Activities o fragments). Esto provocaría que el test falle, se soluciona usando InstantTaskExecutorRule, después de esto, los cambios LiveData son síncronos.
