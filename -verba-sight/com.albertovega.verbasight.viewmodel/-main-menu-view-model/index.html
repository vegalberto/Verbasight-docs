open class MainMenuViewModel

ViewModel del menú principal de la aplicacion VerbaSight.

Esta clase utiliza el patrón MVVM y expone, mediante LiveData, una lista de elementos de menu que permiten al usuario acceder a diferentes funcionalidades de la aplicacion, como el reconocimiento de voz o el reproductor de subtitulos.

Cada MenuItemModel contiene un nombre, un icono y la clase destino de la Activity correspondiente que se abrira al seleccionar cada opcion.
