SpeechRecognitionViewModel

open class SpeechRecognitionViewModel

SpeechRecognitionViewModel es la clase encargada de gestionar toda la lógica relacionada con el reconocimiento de voz en la aplicación VerbaSight.

Forma parte del patrón de arquitectura MVVM, actuando como intermediario entre la interfaz de usuario (SpeechRecognitionActivity) y el motor de reconocimiento de voz Vosk. Su objetivo es mantener el estado de la transcripción durante la sesión, gestionar el servicio de escucha y exponer los datos necesarios para actualizar la vista mediante androidx.lifecycle.LiveData.

La lógica implementada incluye:

  • Gestión de los resultados parciales (actualización en tiempo real mientras el usuario habla)
  • Acumulación de las últimas 3 frases finales reconocidas para mostrarlas a continuación del parcial
  • Gestión de los tiempos relativos para cada frase reconocida y conversión a objetos com.albertovega.verbasight.model.Subtitle
  • Inicio y parada del servicio de escucha de voz
  • Formateo de texto y control de sincronización para exportaciones

Es utilizado directamente por SpeechRecognitionActivity y trabaja en conjunto con la clase de aplicación personalizada com.albertovega.verbasight.core.VerbasightApp, desde donde se obtiene el modelo de voz previamente cargado.
