open class SubtitleViewModelTest

Pruebas unitarias para SubtitleViewModel.

Estas pruebas verifican el comportamiento del ViewModel cuando se cargan subtítulos, se busca una posición específica o se ajusta el tiempo manualmente.

Se usa InstantTaskExecutorRule para forzar la ejecución síncrona de LiveData y evitar errores en los tests. De la misma manera se activa un "modo de prueba" dentro del ViewModel ya que si no, ViewModel ejecutaría un Timer que avanza en segundo plano y produce errores en los test.
